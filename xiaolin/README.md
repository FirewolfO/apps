# 小林学习 Android

一个面向手机阅读的 `xiaolincoding.com` 学习客户端。应用通过内置 WebView 实时呈现原站内容，先在设备本地保存学习记录，也可通过同步码在多台 Android 设备之间同步：

- 最近阅读页面与滚动位置
- 每页显式完成确认
- 阅读页支持当前专题内的上一节、下一节及“完成并下一节”
- 已完成列表和最近浏览记录
- 按“系列 → 专题 → 章节/文章”浏览完整目录
- 内置 3 个系列、16 个专题、307 篇文章索引
- 支持“跟随系统 / 浅色模式 / 深色模式”，原生页面和阅读页使用一致外观

## 完整版与精简版

- **完整版**：保留现有 307 篇原站目录和实时网页阅读，原有学习进度继续使用
  `xiaolin_learning_progress`；1.5.0 首次启动将旧记录原子转换为支持同步的格式，保留旧数据以便恢复，不重置进度。
- **精简版**：内置 77 个高频面试重点和 28 张响应式流程/结构图，无网络时也可阅读；
  每个重点包含“30 秒回答、核心要点、面试官常追问、易错提醒”，并提供原文入口。
- 首页双按钮和各原生页面右上角都可以切换版本；精简版使用独立的
  `xiaolin_learning_progress_compact`，两个版本的完成、浏览、最近阅读和滚动位置互不影响。
- 当前选择记录在 `xiaolin_study_settings`，只是决定下次打开时显示哪个版本，不会合并进度。

## 外观模式

首页“外观模式”入口可切换跟随系统、浅色和深色三种模式。选择保存在
`xiaolin_appearance_settings`；深色模式会同步适配原生目录、学习记录、弹窗、系统状态栏、
完整版网页阅读和精简版离线速记页，不会影响两套学习进度。

目录由官网当前侧边栏生成，包括图解系列、后端八股面试系列和 AI Agent 面试八股系列。阅读正文时需要联网，目录和学习进度保存在设备本地。

## 跨设备同步（1.5.0 起）

1. 所有设备覆盖安装 1.5.0 或更新版本，不要卸载旧版。
2. 第一台设备：首页 → 跨设备同步 → 创建同步码，复制生成的同步码。
3. 其他设备：首页 → 跨设备同步 → 输入已有同步码 → 连接并同步。

同步包括完整版、精简版各自的已完成/撤销完成、最近阅读和阅读位置。两种版本互不混合。
首次连接合并本机和云端记录；编辑后约 1.5 秒上传，前台每 30 秒拉取一次，切回应用和离开应用也会尝试同步。
断网时继续本地学习，失败后自动退避重试，也可点击“立即同步”。同步码配对成功后，状态会显示上次同步时间。
阅读位置使用文章滚动比例适配不同屏幕；同步不会强行跳转正在阅读的页面，重新打开文章时恢复远端位置。

进度按访问、完成、位置三个字段独立合并；使用逻辑版本和设备 ID 决定冲突结果，不依赖手机时钟。
同步后做出的新操作优先于已见过的旧操作；两台设备同时离线修改同一字段时，逻辑版本较大者优先，
相同版本按设备 ID 固定排序，确保所有设备最终一致。撤销完成保留明确记录，旧设备重连不会复活旧状态。

同步码是随机生成的 128 位访问凭据，不是公开用户名；持有码的人可以访问和修改对应进度，请只在自己的设备使用。
凭据只通过 HTTPS Authorization 请求头传输，服务端仅保存其 SHA-256 摘要；本机同步凭据和设备 ID 不进入系统备份。
停止本机同步保留本机与云端学习记录，其他已配对设备继续使用原同步码。请自行保存同步码，丢失后无法按账号找回。

同步后端位于同仓库 `admin/src/xiaolin-sync.js`，通过 App Center 提供服务，协议说明见 `../admin/README.md`。
它是客户端内部协议，不属于工作区各系统的 OpenAPI，无现有 Go/Java/Python SDK 需要同步。

## 构建

需要 JDK 17 和 Android SDK 35。

```bash
# 在 apps 仓库根目录执行
xiaolin/gradlew -p xiaolin testDebugUnitTest lintDebug assembleDebug
```

调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

重新同步官网目录：

```bash
python3 tools/build_catalog.py
```

重新校验并生成精简版目录：

```bash
python3 tools/build_compact_catalog.py
```

本站文章和图片版权归小林coding原作者所有；精简版为面试要点的原创整理与自绘图示，
不复制或再发布原站文章和图片。

## 应用升级

应用从 `https://apps.lxvb.top/api/apps/xiaolin/latest` 检查新版本。发现新版后只显示确认弹窗，
只有用户点击“同意并下载”才会启动系统下载和覆盖安装。应用 ID、签名和 SharedPreferences
路径保持不变，因此覆盖升级会保留完整版与精简版历史进度；不要先卸载旧版。

公开下载页面为 `https://apps.lxvb.top/xiaolin`。
